# Unity-BatmanArkhamCombat

An Arkham-style free-flow brawl: BH3 behaviour trees against a combo system, in two scenes. `Assets/CombatArena.unity` plays on capsules and needs nothing. `Assets/CombatDemo.unity` plays the same fight on rigged characters and needs two Asset Store packs imported first; `Assets/ArkhamCombat/README.md` says which, and everything else.
